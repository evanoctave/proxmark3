# XC2S15 Support (PLATFORM=PM3XC2S15) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the firmware run on a PM3 Easy style clone fitted with a Xilinx XC2S15-VQ100 instead of the XC2S30.

**Architecture:** Add a `PM3XC2S15` platform mirroring the existing `PM3ULTIMATE` (XC2S50) pattern: new FPGA build targets producing XC2S15 bitstreams from unchanged HDL, a new `FPGA_TYPE`/`FPGA_CONFIG_SIZE` pair, and platform blocks in both the Makefile and CMake build. Bitstreams are synthesized through the repo's GitHub Actions ISE workflow on a fork.

**Tech Stack:** GNU make, CMake, Xilinx ISE 10.1 (in CI docker), arm-none-eabi-gcc, `gh` CLI.

Spec: `docs/superpowers/specs/2026-11-01-xc2s15-support-design.md`
